# 캐치노트

PDF 강의자료에 필기하면서 강의를 녹음하고, 나중에 **필기를 누르면 그 필기를 하던 순간의 녹음**을 들려주는 웹앱입니다.

**열기:** https://otwdukeee22-beep.github.io/lecture-navi/

## 쓰는 법

1. **+ PDF 열기**로 강의자료 PDF를 고릅니다.
2. **● 녹음**을 누르고, 도구막대에서 **펜**을 골라 필기합니다.
3. 수업이 끝나면 **■ 정지**를 누릅니다.
4. **보기** 모드에서 필기를 누르면 그 필기를 쓰기 2초 전부터 녹음이 재생됩니다.
5. **기록**에서 녹음 목록과 끊긴 시간을 보고, 녹음을 파일로 저장할 수 있습니다.

아이폰·아이패드에서는 사파리로 연 뒤 **공유 → 홈 화면에 추가**하면 앱처럼 쓸 수 있습니다.

## 알아 둘 점

- PDF, 필기, 녹음은 **쓰는 기기의 브라우저 안에만** 저장됩니다. 서버로 올라가지 않고, 다른 기기로 옮겨지지도 않습니다.
- 아이폰·아이패드는 다른 앱으로 넘어가면 녹음이 끊길 수 있습니다. 돌아오면 새 녹음으로 자동으로 이어지고, 끊긴 시간은 **기록**에 남습니다.
- 녹음하기 전에 교수님께 녹음 동의를 받아 주세요.
